# TheScarmsWords

VB6 shaped-window demo (`TheScarmsWord.exe`) by Dave Scarmozzino of TheScarms.com: nine borderless letter forms (T, h, e, S, c, a, r, m, s) use polygon window regions and gradient fills to spell "The Scarms" across the desktop. Open `TheScarmsWords.vbp` in the VB6 IDE.

**Source last updated:** 2000-07-13 · **Language:** VB6 · **Target:** VB6 Win32 · **Output:** WinForms exe
